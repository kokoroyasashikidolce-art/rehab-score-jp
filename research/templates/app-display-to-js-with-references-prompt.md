# 更新ルール

- 既存JSの構造はできるだけ変更しない
- `export const 〇〇`、`id`、`name`、`shortName`、`categories`、`tags`、`domains`、`showTotal` は変更しない
- 更新対象は主に `tabs`のみ とする
- `overview` タブには「概要タブ」の内容をそのまま入力する。適宜読みやすいように改行を加える。
- `tips` タブには「豆知識タブ」の内容をそのまま入力する。適宜読みやすいように改行を加える。
- `references` には、「参考文献」の内容をそのまま入力する。
- 参考文献番号と本文中の引用番号の対応を崩さない
- 入力された内容以外の医学情報を追加しない。原文をそのまま維持する。
- 不明な項目は推測で補完しない原文をそのまま維持する。
- 既存JSに存在する計算ロジック、選択肢、スコアリング、export形式は変更しない
- JavaScriptとしてそのまま貼り替え可能な形にする
- MCID・MDC・基準値の確立した存在がないものは、「MCID・MDC・基準値」の項目は省略する

# 出力ルール

- 更新後のJavaScriptコードのみ出力する
- 解説文は不要
- markdownは使用しない
- コードブロックのみ出力する
- overview:、tips:の中身はスマホ表示板で読みやすいように適宜改行を加える

# references において、入力された参考文献を全て変換する。

例：

references: [
{
id: 1,
citation:
"Berg K, et al. Measuring balance in the elderly. Can J Public Health. 1992.",
},
]
